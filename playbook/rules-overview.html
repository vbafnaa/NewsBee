Page checks

Every page discovery finds goes through these four groups of checks.

Safety

Never open private addresses, and always follow crawl delays.

Can it be switched off? No, always on.

Quality

Reject known repost and aggregator sites, and pages clearly about another place.

Can it be switched off? No, always on in Pipeline 1 discovery, whatever the run's guardrails.

Access

Robots, AI opt-outs, noai and nosnippet tags, the terms check, and the never-read list.

Can it be switched off? Yes, by the Access setting: Respect follows them, and Relaxed skips the ones ticked (none ticked means all). Relaxed is local only.

Evidence

Locality and freshness facts: names, official site, addresses, and the dates found with where each came from.

Can it be switched off? Not a pass-or-fail rule. Code decides only clear cases and marks the rest unclear, for the Gemini check.

How to edit a rule

  1. Find the rule above and note its id, such as safety.stage1.sheriff.
  2. Open that category's file in the playbook folder, such as playbook/safety.yaml, and find the id.
  3. Change the words. Keep the id the same, because results are tied to it. Keep text inside its single quotes, and write a single quote as two.
  4. In apps/journalist-site, run npm run playbook. It checks your edit and refreshes this page, the AI's skill and the app's copy. A mistake stops it with a message naming the rule.
  5. Run npm test. The snapshot tests will fail on purpose, showing what your edit changes. Have an engineer review that before updating them.
