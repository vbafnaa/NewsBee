Cleanup notes

Where the system drifts

These came up while pulling values from the stylesheet. None of them are visible bugs, but fixing them would make the system easier to maintain.

  • About 35 one-off font sizesSizes such as 9.5, 10.5, 11.5, 12.5, 13.5, 14.5, 15.5 and 16.5px sit alongside Tailwind's scale. Most could be folded into 6–8 named sizes.
  • About 20 one-off line heightsValues from 1.05 to 1.72. Three or four (tight, snug, normal, relaxed) would cover most cases.
  • Letter spacing on labels variesUppercase labels use anything from 0.06em to 0.22em. One or two values would keep them consistent.
  • Some spacing is off the 4px gridA few gaps and margins use 3, 5, 9, 13, 15, 18, 22 and 34px.
  • Headline weight doesn't match the font fileHeadings ask for weight 600, but only GT Super Medium (500) is loaded, so browsers either fake the bold or fall back to 500.
